# Сайт консультанта — Марьян Кротов

Персональный сайт эксперта-консультанта по инвестиционно-строительным проектам.
Статика без сборки и бэкенда: чистый HTML + CSS + JavaScript.

## Структура

```
site/
├── index.html                 — страница сайта (русский язык, /)
├── en/
│   └── index.html             — страница сайта (английский язык, /en/)
├── assets/
│   ├── styles.css             — стили, светлая и тёмная темы
│   ├── main.js                — тема, меню, анимации, форму заявки, язык
│   ├── og-cover.png           — картинка для превью ссылки (1200×630)
│   ├── cv-krotov.pdf          — резюме, русский (10 страниц)
│   ├── cv-krotov-en.pdf       — резюме, английский (9 страниц)
│   ├── service-express-audit.pdf — описание услуги, русский
│   ├── service-express-audit-en.pdf — описание услуги, английский
│   ├── certificate-economy-business-2026.pdf
│   │                            — сертификат о публикации, русский (оригинал журнала)
│   └── certificate-economy-business-2026-en.pdf
```

### Документы в PDF

Русские и английские версии лежат рядом и различаются суффиксом `-en`.
Английские версии сделаны в той же визуальной системе, что и сайт: палитра и
типографика взяты из `assets/styles.css`, шрифты — Source Serif 4, Manrope и
JetBrains Mono, встроенные в PDF как подмножества (текст остаётся выделяемым
и ищется).

Английское резюме — 9 страниц A4 с кликабельным оглавлением: ссылки в
оглавлении ведут на нужные страницы, номера страниц в оглавлении совпадают
с фактическими.

В потоках PDF используется фильтр ASCII85, а в заголовке — маркер
`%PDF-ASCII-MARKER` вместо бинарного. Это сделано, чтобы файлы можно было
передавать через текстовые каналы (например, через API GitHub). На отображение,
печать и извлечение текста это не влияет.

Контакты во всех шести PDF приведены к виду сайта: e-mail `krotovmarik@gmail.com`,
Telegram `@Mark0nya`. Номер телефона не публикуется. В русском резюме и описании
услуги адрес заменён прямо в текстовом слое документа, поэтому текст остаётся
выделяемым, а ссылка `mailto:` — рабочей.

## Языки

Сайт двуязычный: русский (`/`) и английский (`/en/`).

- Это две отдельные HTML-страницы, а не переключение текста скриптом. Так каждая
  версия получает свой `lang`, канонический URL, мета-описание, Open Graph и
  разметку Schema.org — это важно для поисковой выдачи.
- Переключатель языка находится в шапке (RU / EN) и в мобильном меню.
  Ссылки ведут на соответствующую страницу, поэтому ими можно пользоваться без
  JavaScript и они индексируются.
- При переходе на другой язык сохраняется текущий раздел страницы: `main.js`
  переносит якорь (`#service`, `#pricing` и т. д.) в адрес ссылки, потому что
  идентификаторы секций в обеих версиях совпадают.
- Выбор темы общий для обеих версий (`localStorage`, ключ `mk-theme`).
- Связи между версиями объявлены через `hreflang` (`ru`, `en`, `x-default`)
  в `index.html` и `en/index.html`, а также в `sitemap.xml`.
- Тексты интерфейса (подписи мобильного меню, сообщение формы) берутся из
  справочника `I18N` в `assets/main.js` — язык определяется по атрибуту `lang`
  корневого элемента.

Если меняете тексты, обновляйте обе версии: русский `index.html` и английский
`en/index.html`, а также JSON-LD в каждой из них.

## Как открыть локально

Откройте `index.html` в браузере. Сборка не требуется.

Локальная проверка английской версии (из корня репозитория):

```bash
cd site && python3 -m http.server 8000
```

Русская версия — `http://localhost:8000/`, английская — `http://localhost:8000/en/`.


## Как разместить в интернете

Сайт — полностью статический, подойдёт любой хостинг (Timeweb, Beget, Reg.ru, Netlify, Vercel, GitHub Pages, nginx на своём VDS):

1. Загрузите **содержимое папки `site/`** в корень сайта (для nginx/Apache — в `public_html` / `www`).
2. Убедитесь, что в корне лежит `index.html`.
3. Сборка не нужна. Если используете nginx, отдавайте статику напрямую:

```nginx
server {
    listen 80;
    server_name example.ru;
    root /var/www/site;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

4. Канонический адрес, Open Graph, Twitter Card и JSON-LD настроены на
   `https://consultingwebsite-marian.netlify.app/` (русская версия) и
   `https://consultingwebsite-marian.netlify.app/en/` (английская версия).
   При смене домена обновите эти адреса в `index.html` и `en/index.html`,
   а также адреса в `robots.txt` и `sitemap.xml`.
5. Для продакшена рекомендуется подключить домен и выпустить TLS-сертификат (Let's Encrypt).

## Темы

- Переключатель в шапке (иконка солнца / луны).
- Выбор сохраняется в `localStorage` (ключ `mk-theme`).
- Если выбор не сделан, сайт следует системной теме ОС и меняет её «на лету».
- Учитывается `prefers-reduced-motion` — анимации отключаются.

## Форма заявки

Форма ничего не отправляет на сервер: она собирает текст из полей и открывает Telegram
с готовым сообщением (`https://t.me/Mark0nya?text=...`). Если нужен приём заявок
в почту или CRM, замените обработчик в `assets/main.js` (событие `submit` формы `#leadForm`)
на свой запрос к API.

## Поисковая оптимизация

Главная страница содержит SEO-заголовок и описание, единый канонический HTTPS-адрес,
абсолютные ссылки на изображение для социальных сетей и структурированные данные
Schema.org (WebSite, WebPage, Person, Service, ImageObject и FAQPage). Сведения в
разметке должны совпадать с видимым содержимым. Разметка FAQ не гарантирует
расширенного сниппета в Google.

Что сделано в разметке:

- `Person` — e-mail, язык общения (`ru`, `en`), alma mater и подтверждение
  квалификации НОСТРОЙ;
- `Service` — стартовая цена (`offers`, 250 000 ₽) и регион работы;
- `WebPage` — `primaryImageOfPage` с картинкой `og-cover.png` (1200×630);
- у русской страницы добавлен `og:locale:alternate` для английской версии.

Длина мета-описания удерживается в пределах 150–160 символов, заголовка — 55–70,
чтобы сниппет в поиске не обрезался. Для доступности в начале страницы есть
ссылка «Перейти к содержанию» (`.skip-link`), которая видна только при
получении фокуса с клавиатуры.

`robots.txt` разрешает обход сайта и указывает на `sitemap.xml`. Карта содержит
два самостоятельных URL — `/` и `/en/`; разделы с якорями не являются отдельными
страницами. Настройка Netlify перенаправляет `/index.html` на `/` с кодом 301.

После публикации добавьте сайт в Яндекс Вебмастер и Google Search Console,
подтвердите владение через выданную сервисом запись DNS или метатег и отправьте
`https://consultingwebsite-marian.netlify.app/sitemap.xml`. Затем проверяйте
индексацию, поисковые запросы и переходы. Данные подтверждения выдаются владельцу
в этих сервисах; счётчик Метрики сам по себе не подтверждает владение.

При изменении услуги обновляйте одновременно видимый текст, FAQ и JSON-LD.
При добавлении самостоятельных страниц включайте их канонические URL в sitemap.
